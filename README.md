# Work Requirement 2 – Python Practice Project

## Overview
This repository contains solutions to selected exercises for Work Requirement 2 in the Backend Essentials course. The purpose of the assignment is to practice basic Python concepts such as file handling, error handling, and program structure.


## How to Run the Scripts


These scripts are written in Python 3 and are meant to be run from the command line.

1. Make sure Python 3 is installed on your computer.
   Python 3 is required because the scripts use modern Python features such as `input()`, f-strings, and current file handling syntax that are not supported in older Python versions.

2. Download or clone this repository to your computer.

3. Open a terminal and navigate to the project folder:
   Workrequirement2

4. All Python scripts are located in the `src` folder.
   To run a script, use the following command format:

   python src/<script_name>.py


5. Follow the instructions shown in the terminal.
   Some scripts will ask for user input.


---

### Exercise 1: File to List Converter
This script prompts the user for a filename, reads all lines from the file, removes whitespace, and prints the result as a Python list. The exercise focuses on working with files and handling errors when a file does not exist.
